# Security Advisory for NetBackup

## Revision History

2026-10-12: Added link to CVE\
2026-08-28: Initial version

## Summary

This advisory addresses a security vulnerability affecting the NetBackup Administration Console web interface. The issue is rated Medium severity. Customers are encouraged to upgrade as soon as possible.

## Issue

### HTML Injection in the NetBackup Administration Console Web Interface

The NetBackup Administration Console web interface did not adequately sanitize user-supplied input. An unauthenticated attacker that could persuade an authenticated administrator to follow a specially crafted link could cause arbitrary HTML content to be rendered within the administrator’s browser session in the context of the trusted console application. Successful exploitation could be leveraged to conduct phishing attacks within the administrative interface, redirect administrators to attacker-controlled resources, or manipulate the visual presentation of the console in ways that may facilitate further social engineering.

- CVE ID: [CVE-2026-108925](https://nvd.nist.gov/vuln/detail/cve-2026-108925)
- CVSS v3.1 Base Score: 6.1 (Medium) — CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N
- CVSS v4.0 Base Score: 5.1 (Medium) — CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:P/VC:N/VI:L/VA:N/SC:L/SI:L/SA:N

#### Prerequisites

- The attacker must be able to persuade an authenticated administrator to follow a specially crafted URL targeting the NetBackup Administration Console.

#### Mitigation

- Restrict access to the NetBackup Administration Console to trusted network segments and enforce strict access controls on who can reach the administrative interface. Educate administrators to be cautious of unsolicited links to the console from untrusted sources. No configuration change completely eliminates the risk; upgrading to the remediated release is required.

#### Affected Versions

- NetBackup: Versions before 11.2
- NetBackup Flex Appliance: All version running NetBackup before 11.2

#### Remediation

- NetBackup: Upgrade to version 11.2 or later
- NetBackup Flex Appliance: Upgrade NetBackup to 11.2 or later
